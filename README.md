## User Flow Overview

The application is designed to provide a simple and intuitive browsing experience. Users can navigate through the app using one of the following flows:

### Main Flow
1. **Home Screen**
   - Users start on the home screen.
   - They can browse available categories or use the search bar.

2. **Category Selection**
   - Users select a category to explore.
   - This leads to a list of relevant subcategories.

3. **Subcategories Screen**
   - Users choose a subcategory that best matches their intent.
   - This helps narrow down the results.

4. **Filters Screen**
   - Users refine their search by applying filters such as price, features, or other attributes.

5. **Results Screen**
   - Filtered results are displayed.
   - Users can browse listings and select an item to view more details.

---

   - Users enter a keyword directly into the search bar.

## Screen Descriptions

### Home Screen
Welcome screen where users can start their search by typing in the search bar or browsing categories. It serves as the main entry point to the application.

### Subcategories Screen
Allows users to select a more specific category, helping narrow down the search results for better relevance.

### Filters Screen
Provides options to refine search results using criteria such as price, features, and other relevant attributes.

### Results Screen
Displays the list of items matching the user's search or selected filters. Users can adjust their search or filters and select items to view detailed information.
